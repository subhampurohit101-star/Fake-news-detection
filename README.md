# 📰 Fake News Detection System

This project is a **Machine Learning-based web application** that detects whether a news article is **Real or Fake** using Natural Language Processing (NLP) techniques.

---

## 🚀 Project Overview
The goal of this project is to build a classification model that can analyze news text and predict its authenticity. It also includes an interactive web interface for real-time predictions.

---

## ✨ Features
- 🔍 Classifies news as **Real or Fake**
- 🧠 Uses **Logistic Regression** for classification
- 📊 Text processing using **TF-IDF Vectorization**
- ⚡ Real-time prediction with **Streamlit UI**
- 📈 High accuracy with balanced dataset

---

## 🛠️ Tech Stack
- Python  
- Pandas  
- Scikit-learn  
- Streamlit  
- Natural Language Processing (NLP)
